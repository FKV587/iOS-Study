**鲁棒性（Robustness）**指的是**系统或程序在面对异常情况或不确定因素时，仍然能够稳定运行的能力**。  

在 **Swift 的错误处理机制** 中，`do-catch` 和 `throws` 让代码**显式**地处理错误，避免程序崩溃，提高稳定性。  

---

## **✅ 为什么 Swift 的错误处理能提高鲁棒性？**
1. **避免程序崩溃**
   - 通过 `do-catch` 结构，程序可以**捕获**错误，而不是直接崩溃。
   ```swift
   do {
       let data = try loadData()
   } catch {
       print("❌ 发生错误: \(error)")
   }
   ```
   **没有 `do-catch`**，如果 `loadData()` 抛出错误，程序会直接崩溃。

2. **可预见的错误处理**
   - `throws` 让函数的调用方**必须**处理错误，避免忽略潜在问题：
   ```swift
   func fetchData() throws -> String {
       throw NSError(domain: "Network", code: -1, userInfo: nil)
   }

   do {
       let result = try fetchData()
   } catch {
       print("捕获到错误：\(error)")
   }
   ```

3. **不同错误的精确处理**
   - `catch` 可以处理**特定错误类型**，提高代码的**可维护性**：
   ```swift
   enum FileError: Error {
       case fileNotFound
       case noPermission
   }

   func readFile() throws {
       throw FileError.fileNotFound
   }

   do {
       try readFile()
   } catch FileError.fileNotFound {
       print("📂 文件未找到")
   } catch {
       print("🚨 其他错误")
   }
   ```

---

## **📌 结论**
Swift 的 `throws` 机制可以**显式声明错误**，`do-catch` 允许**优雅处理异常**，避免崩溃，提高代码的鲁棒性（稳定性和容错能力）。
